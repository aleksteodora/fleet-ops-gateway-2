# FleetOps Gateway Frontend

FleetOps Gateway Frontend is the web application used by FleetOps Gateway users to search vehicles, review search history, view statistics, and access other FleetOps functionality.

The frontend is developed as part of the FleetOps Gateway internship project.

## Features

The initial frontend scope is expected to include:

- Vehicle search by VIN
- Vehicle details
- Search history
- Search filtering and pagination
- Dashboard and statistics

The final feature set and UI details will be defined during the project.
