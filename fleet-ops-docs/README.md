# FleetOps Gateway Documentation

This repository contains project-wide documentation for the FleetOps Gateway internship project.

## Purpose

The documentation covers project requirements, development conventions, architecture decisions, API contracts, and other information shared across the FleetOps Gateway components.

## Project Components

- `fleetops-gateway` – backend service responsible for communication with provider systems
- `fleetops-provider` – service that simulates Free and Premium vehicle data providers
- `fleetops-frontend` – frontend application
- `fleetops-docs` – project-wide documentation

The exact architecture and responsibilities will be defined during the project together with the students.

## Documentation

Planned documentation includes:

- Project overview
- Business requirements
- Development guidelines
- Git workflow
- Architecture decisions
- API contracts
- Database documentation
- Local development setup
- Technical notes


## Status

Documentation will evolve throughout the project.
